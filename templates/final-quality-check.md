# 最終品質チェック

## 企画

- [ ] 誰に売るnoteか明確である
- [ ] 読者の悩みが具体的である
- [ ] 読後の変化が明確である
- [ ] 他のnoteとの差別化がある

## 本文

- [ ] 導入で読み続ける理由がある
- [ ] 無料部分だけでも価値がある
- [ ] 有料部分に核心的な手順がある
- [ ] テンプレート、実例、チェックリストがある
- [ ] 章ごとの役割が明確である

## 販売

- [ ] タイトルがベネフィットを伝えている
- [ ] 販売ページが購入前の不安に答えている
- [ ] 価格の理由が説明できる
- [ ] CTAが自然である
- [ ] 購入特典がある

## リスク

- [ ] 根拠のない売上保証がない
- [ ] 誇大表現がない
- [ ] 実績風の表現が事実に基づいている
- [ ] ステルスマーケティングに見える導線がない
- [ ] 読者に過度な期待を抱かせていない

## 運用

- [ ] 追記計画がある
- [ ] 関連note導線がある
- [ ] 無料note導線がある
- [ ] SNS投稿計画がある
- [ ] 改善指標が決まっている
