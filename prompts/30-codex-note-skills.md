# Codexで売れるnoteを量産する30スキル

このファイルは、Claude Code向けの「30スキル」構想をCodex用に置き換えた実行プロンプト集です。

使い方:

- 1本のnoteごとに `notes/YYYY-MM-topic-slug/` を作る。
- スキル1から順番に実行する。
- 各スキルの出力を該当ファイルへ保存する。
- 不明な情報は仮説として明記し、検証方法も出す。

## Phase1: 作る

### スキル1: 市場リサーチ

目的: noteで売れる可能性があるジャンル、テーマ、切り口を見つける。

Codexへの依頼文:

```text
スキル1「市場リサーチ」を実行してください。
対象ジャンルは「{ジャンル}」です。
noteで売れる可能性があるテーマ候補を3つ出してください。
各テーマについて、想定読者、悩み、購入理由、競合度、収益性、差別化余地を評価してください。
推測は推測と明記し、追加で調べるべき項目も出してください。
出力は notes/{slug}/research.md に保存できる形式にしてください。
```

出力:

- テーマ候補3つ
- 需要度、競合度、収益性
- 勝てる切り口
- 検証すべき項目

### スキル2: ペルソナ設計

目的: 誰に売るnoteなのかを1人の読者像に落とす。

Codexへの依頼文:

```text
スキル2「ペルソナ設計」を実行してください。
research.mdの内容をもとに、最も購入可能性が高いペルソナを1人設計してください。
年齢、職業、状況、悩み、欲求、購入を迷う理由、購入を決める瞬間、普段見ているSNSや情報源を具体化してください。
このペルソナが思わず購入したくなるnoteの条件も出してください。
```

### スキル3: テーマ・コンセプト設計

目的: noteの約束を一言で定義する。

Codexへの依頼文:

```text
スキル3「テーマ・コンセプト設計」を実行してください。
市場リサーチとペルソナをもとに、このnoteのコンセプト文を50字以内で5案作ってください。
それぞれについて、読者のBefore、After、差別化ポイント、無料部分で見せる価値、有料部分で渡す核心を整理してください。
```

### スキル4: 競合分析

目的: 似た商品との違いを作る。

Codexへの依頼文:

```text
スキル4「競合分析」を実行してください。
同ジャンルで売れているnoteや有料コンテンツを想定し、タイトル傾向、価格帯、訴求、弱点、読者の不満を分析してください。
そのうえで、このnoteが勝つための差別化軸を3つ提示してください。
実在データが必要な箇所は、調査すべきURLや検索語句も出してください。
```

### スキル5: 価格設計

目的: 感覚ではなく商品価値と導線から価格を決める。

Codexへの依頼文:

```text
スキル5「価格設計」を実行してください。
このnoteの想定価値、読者の購買力、競合価格、上位商品への導線をもとに、販売価格を3案出してください。
初回価格、通常価格、値上げタイミング、セット販売案、購入者特典案も提示してください。
価格の根拠とリスクも明記してください。
```

### スキル6: ベネフィット言語化

目的: 読者が買う理由を言葉にする。

Codexへの依頼文:

```text
スキル6「ベネフィット言語化」を実行してください。
このnoteを読むことで読者が得る機能的ベネフィット、感情的ベネフィット、時間短縮、失敗回避、収益機会を整理してください。
タイトル、サムネ、販売ページ、告知文に使える短いフレーズを20個出してください。
誇大表現になりそうな表現は安全な言い換えも付けてください。
```

### スキル7: 目次・構成設計

目的: 無料部分から有料部分まで自然に読み進める構成を作る。

Codexへの依頼文:

```text
スキル7「目次・構成設計」を実行してください。
スキル1から6の結果をもとに、noteの章立てを作ってください。
無料部分、有料ライン直前、有料部分、購入後の満足ポイントを明確にしてください。
各章の目的、読者感情、文字数目安、入れる具体例、CTAを表で整理してください。
```

### スキル8: 本文執筆

目的: 設計に沿って本文を生成する。

Codexへの依頼文:

```text
スキル8「本文執筆」を実行してください。
outline.mdの構成に沿って、note本文を章ごとに執筆してください。
抽象論だけにせず、手順、具体例、テンプレート、チェックリストを入れてください。
まず第1章から第3章までを書き、各章の最後に次を読みたくなる接続文を入れてください。
```

### スキル9: 校正・品質チェック

目的: 読みやすさ、販売力、法務リスクを確認する。

Codexへの依頼文:

```text
スキル9「校正・品質チェック」を実行してください。
draft.mdを読み、誤字脱字、冗長表現、読者への刺さり方、論理の飛躍、誇大表現、景品表示法リスク、購入後満足度の不足をチェックしてください。
修正すべき箇所と修正文を表で出してください。
最後に改善後の完成度を100点満点で評価してください。
```

### スキル10: タイトル・サムネイル生成

目的: クリックされる入口を作る。

Codexへの依頼文:

```text
スキル10「タイトル・サムネイル生成」を実行してください。
このnoteのタイトル案を10個作ってください。
切り口は、数字、逆説、悩み直撃、未来像、テンプレート訴求、初心者向け、上級者向けに分けてください。
各タイトルに対応するサムネ文言、デザイン方向、避けるべき表現も出してください。
```

## Phase2: 売る

### スキル11: 無料部分・有料部分の設計

```text
スキル11「無料部分・有料部分の設計」を実行してください。
draft.mdを読み、無料部分で信頼を得る範囲、有料ラインを置く位置、有料部分に入れる核心を設計してください。
有料ライン直前の引き文を3パターン作ってください。
```

### スキル12: 販売ページ文章生成

```text
スキル12「販売ページ文章生成」を実行してください。
このnoteの販売ページ文を作ってください。
冒頭の問題提起、読者の悩み、得られる変化、内容一覧、購入者に向いている人、向いていない人、価格への納得、CTAを含めてください。
煽りすぎず、具体性で購入したくなる文章にしてください。
```

### スキル13: 価格・販売設定

```text
スキル13「価格・販売設定」を実行してください。
スキル5の価格設計をもとに、初回価格、通常価格、値上げ条件、特典、販売期間、セット販売案を確定してください。
売上最大化だけでなく、購入後満足度とブランド毀損リスクも考慮してください。
```

### スキル14: 感情設計

```text
スキル14「感情設計」を実行してください。
販売ページと告知の中に、共感、問題の明確化、解決策、信頼、未来像、行動理由を自然に組み込んでください。
希少性や損失回避を使う場合は、事実に基づく範囲に限定してください。
```

### スキル15: 初速戦略設計

```text
スキル15「初速戦略設計」を実行してください。
リリース7日前、3日前、前日、当日、翌日、3日後、7日後の行動スケジュールを作ってください。
各日の投稿内容、目的、CTA、購入者フォロー、改善確認項目を整理してください。
```

### スキル16: X告知ポスト生成

```text
スキル16「X告知ポスト生成」を実行してください。
リリース前、当日、翌日、リローンチ用のX投稿を合計10本作ってください。
単発、スレッド冒頭、体験談風、失敗回避、テンプレート訴求、実績共有風に切り口を分けてください。
```

### スキル17: メルマガ・LINE告知文生成

```text
スキル17「メルマガ・LINE告知文生成」を実行してください。
メルマガ告知文、LINE短文、購入者へのお礼、未購入者へのフォロー文を作ってください。
件名、本文、CTA、送信タイミングを含めてください。
```

### スキル18: 購入者フォローアップ設計

```text
スキル18「購入者フォローアップ設計」を実行してください。
購入直後、3日後、7日後、30日後のフォローアップ文を作ってください。
満足度向上、実践促進、レビュー依頼、次の商品への自然な導線を含めてください。
```

### スキル19: レビュー・口コミ獲得設計

```text
スキル19「レビュー・口コミ獲得設計」を実行してください。
購入者がレビューを書きやすい依頼文、Xで感想を投稿しやすいテンプレート、レビュー活用時の許可取り文を作ってください。
過度な見返りやステマに見える設計は避けてください。
```

### スキル20: リローンチ設計

```text
スキル20「リローンチ設計」を実行してください。
このnoteを30日後、60日後、90日後に再販売する計画を作ってください。
更新内容、告知切り口、新規読者向け訴求、既存購入者向け案内、値上げ告知文を含めてください。
```

## Phase3: 運用する

### スキル21: 追記・アップデート設計

```text
スキル21「追記・アップデート設計」を実行してください。
このnoteの価値を上げ続けるための追記テーマを10個出してください。
追記タイミング、追記内容、告知文、購入者への案内文を作ってください。
```

### スキル22: 関連note導線設計

```text
スキル22「関連note導線設計」を実行してください。
このnoteと関連させる無料note、有料note、続編noteを設計してください。
本文内、購入後、プロフィール、SNSからの導線文も作ってください。
```

### スキル23: 無料note設計

```text
スキル23「無料note設計」を実行してください。
有料noteへの集客を目的にした無料noteを3本企画してください。
各無料noteのタイトル、構成、検索キーワード、有料noteへの誘導文を作ってください。
```

### スキル24: SNS誘導設計

```text
スキル24「SNS誘導設計」を実行してください。
このnoteへ継続流入を作るため、X投稿を週5本、4週間分設計してください。
投稿テーマ、本文、CTA、誘導先、再利用できる切り口を表で出してください。
```

### スキル25: 上位商品設計

```text
スキル25「上位商品設計」を実行してください。
このnoteを入口商品として、上位商品への導線を設計してください。
上位商品の候補、価格帯、価値訴求、案内タイミング、購入者限定オファー文を出してください。
```

### スキル26: 売上分析・改善提案

```text
スキル26「売上分析・改善提案」を実行してください。
ビュー数、購入数、購入率、売上、流入元、告知投稿の反応を入力として、改善点を優先度順に出してください。
データが未入力の場合は、必要な計測項目と記録テンプレートを作ってください。
```

### スキル27: タイトル・サムネABテスト設計

```text

現在のタイトルとサムネを改善するA/Bテスト案を3つ作ってください。
テスト期間、判断基準、変更する要素、勝ちパターンの採用条件を出してください。
```

### スキル28: 価格改定設計

```text
スキル28「価格改定設計」を実行してください。
売れ行き、購入率、レビュー、追記状況をもとに、価格改定プランを作ってください。
値上げ幅、告知タイミング、駆け込み購入を促す文、既存購入者への説明文を含めてください。
```

### スキル29: シリーズ化設計

```text
スキル29「シリーズ化設計」を実行してください。

```
