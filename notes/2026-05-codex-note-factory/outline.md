# 構成案

## 無料部分

### 第1章: AIでnoteを書けるのに売れない理由

- 目的: 読者の現状を言語化して共感を作る。
- 内容: 書く力ではなく、作る・売る・運用する仕組みが分断されていることを説明する。
- 有料への接続: 仕組みを30スキルに分解すると、毎回同じ手順で商品化できる。

### 第2章: Codexでnoteを量産する全体像

- 目的: Phase1、Phase2、Phase3の必要性を理解してもらう。
- 内容: 作る10スキル、売る10スキル、運用する10スキルの全体像。
- 有料への接続: 全体像だけではなく、実際にCodexへ投げる指示文が必要だと示す。

### 有料ライン直前

ここから先では、Codexにそのまま読ませて使える30個の実行プロンプトと、note制作フォルダのテンプレートを公開します。

## 有料部分

### 第3章: Phase1「作る」10スキル

- 市場リサーチ
- ペルソナ設計
- テーマ・コンセプト設計
- 競合分析
- 価格設計
- ベネフィット言語化
- 目次・構成設計
- 本文執筆
- 校正・品質チェック
- タイトル・サムネイル生成

### 第4章: Phase2「売る」10スキル

- 無料部分・有料部分の設計
- 販売ページ文章生成
- 価格・販売設定
- 感情設計
- 初速戦略設計
- X告知ポスト生成
- メルマガ・LINE告知文生成
- 購入者フォローアップ設計
- レビュー・口コミ獲得設計
- リローンチ設計

### 第5章: Phase3「運用する」10スキル

- 追記・アップデート設計
- 関連note導線設計
- 無料note設計
- SNS誘導設計
- 上位商品設計
- 売上分析・改善提案
- タイトル・サムネABテスト設計
- 価格改定設計
- シリーズ化設計
- 資産化・ポートフォリオ設計

### 第6章: Codexに読ませるファイル構成

- AGENTS.md
- prompts/30-codex-note-skills.md
- templates/note-brief.md
- templates/sales-page.md
- templates/launch-plan.md
- templates/operations.md
- templates/final-quality-check.md

### 第7章: 1本目を作る実践手順

- 企画ブリーフを書く。
- スキル1から6で売れる設計を作る。
- スキル7から10で本文を作る。
- スキル11から20で販売を作る。
- スキル21から30で運用を作る。

### 第8章: まとめ

- 完璧に準備してからではなく、1本作りながら改善する。
- Codexは文章生成ツールではなく、制作工程を固定化する相棒として使う。
