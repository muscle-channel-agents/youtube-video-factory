# Video Quality Check

## Originality

- [x] The speech is original, not a copied quote compilation.
- [x] The video has one clear theme: disappear for six months and rebuild quietly.
- [x] The video has a beginning, middle, and ending.
- [x] Every symbolic insert has a reason in the scene board.
- [x] The visuals are not just random cinematic B-roll.
- [x] The description clearly states the original production process.

## Monetization Risk

- [x] No celebrity likeness is intentionally used.
- [x] No public figure voice is cloned or imitated.
- [x] No copyrighted movie, sport, interview, or speech clip is used.
- [ ] Music license is safe for YouTube monetization.
- [ ] AI-generated assets are tracked in the project folder or Google Drive asset folder.
- [x] Repeated templates are customized for this specific video.

## Viewer Impact

- [x] The first 5 seconds are strong.
- [x] The main message is clear without reading the description.
- [x] Japanese subtitles feel natural, not machine translated.
- [x] English key phrases are simple enough for Japanese viewers.
- [x] The video gives the viewer a concrete action.
- [x] The final line is memorable.

## Visual Quality

- [ ] At least 40% of the timeline has true motion or AI video clips.
- [ ] AI artifacts are not obvious at normal playback speed.
- [ ] Face shots do not look like a specific famous person.
- [ ] Hands are not distracting or broken.
- [ ] Text stays inside the safe area on mobile and desktop.
- [ ] Color grade is consistent within each chapter.

## Audio Quality

- [ ] Voice is clear over BGM.
- [ ] BGM does not overpower emotional lines.
- [ ] There are intentional pauses.
- [ ] No clipped audio.
- [ ] SFX are subtle.
- [ ] Export has been watched once without skipping.

## Publishing

- [x] Title matches the thumbnail promise.
- [x] Thumbnail is readable at small size.
- [x] Description is English and Japanese.
- [x] Fixed comment includes one action mission.
- [x] Chapters are added if useful.
- [x] Metrics to review are defined.
