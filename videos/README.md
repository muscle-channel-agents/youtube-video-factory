# YouTube Video Factory

This folder stores one production folder per video.

## Folder Format

```text
videos/YYYY-MM-topic-slug/
```

## Minimum Files

```text
brief.md
script.md
scene-board.md
generation-prompts.md
edit-spec.md
publish-pack.md
quality-check.md
metrics.md
assets/
  images/
  video/
  audio/
  exports/
```

## Recommended Order

0. Set the channel direction with `templates/channel-concept.md`, `templates/audience-persona.md`, and `templates/channel-brand-rules.md`.
1. Define the concept with `templates/video-brief.md`.
2. Write the original English speech and Japanese subtitle adaptation with `templates/video-script.md`.
3. Convert the speech into a scene board with `templates/video-scene-board.md`.
4. Create image prompts and image-to-video prompts with `templates/video-generation-prompts.md`.
5. Build the editing plan with `templates/video-edit-spec.md`.
6. Prepare title, thumbnail, description, fixed comment, and Shorts derivatives with `templates/video-publish-pack.md`.
7. Review with `templates/video-quality-check.md`.
8. Record 24-hour and 7-day results with `templates/video-metrics.md`.
